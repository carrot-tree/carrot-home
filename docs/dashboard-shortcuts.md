# 右上角快捷按钮

从主页左上方仪表盘按钮的菜单选择 **仪表盘设置… → 快捷按钮**。

默认沿用“设置 → Carrot Home → 仪表盘”里的全局命令按钮。选择“此仪表盘单独设置”，或“复制全局并单独设置”，即可给每个仪表盘安排不同的入口；现有全局配置不会被改写。

- **添加已安装插件**：先选插件，再选择它实际提供的命令。例如 TaskNotes 的番茄钟入口。未启用或没有可用命令的插件会说明原因，不会自动启用插件。
- **从全部命令添加**：搜索 Obsidian 与插件的已注册命令。
- **添加自定义按钮**：自定名称和图标，运行命令、打开库内 Markdown 笔记，或打开 http、https、obsidian 链接。
- 每个按钮可以启用、停用、更换名称和图标、编辑目标、调整左右顺序或删除。

改动先保留在表单中，点击 **保存快捷按钮** 后应用；切换页签不自动保存。未保存就关闭会放弃本次快捷按钮编辑。保存失败时表单保留，可以修正后重试。

独立配置可以保存为空列表，此时只显示固定的布局编辑按钮。选择“恢复沿用全局设置”并保存后，又会使用全局命令按钮。布局编辑按钮始终保留在最右侧；按钮较多时快捷组可横向滚动。

复制仪表盘会复制其独立配置，两页之后各自修改；布局和全部设置备份会保留独立配置、空列表与沿用状态。插件命令或笔记失效时按钮会显示不可用原因，不会悄悄删除你的配置。

本功能自 2.2.0 起提供。

# Carrot Home 2.2.0 · 安心工作台

本版目标：让主页里的记录、任务与设置可信、可恢复，同时保持现有六卡片布局、顶部晾绳和圆形专注盘。

## 体验设计

| 场景 | 2.2.0 行为 | 验收标准 |
| --- | --- | --- |
| 还原工作台 | 确认前显示备份摘要，解释只恢复布局/设置，不导入笔记；完整验证后再应用 | 带任务卡的备份可还原；29 类卡片配置往返不丢；失败不污染当前设置 |
| 便签正在保存 | 显示保存状态，保存期间锁定编辑与取消/丢弃；原文成功后的重试只清草稿 | 不丢保存后的输入、不重复建便签、丢弃后草稿不复活 |
| 编辑中移动或改名 | 编辑器跟随 Markdown 文件与父目录路径变化 | 后续输入仍能保存或从新路径草稿恢复；外部内容冲突仍拒绝覆盖 |
| 今天开始新一天 | 循环任务按本地当天重新解析实例；快捷与高级计划筛选用当前实例 | 昨天已完成不会藏掉今天任务；缓存不随天数无限增长 |
| 历史重复日历 | 从目标日期附近展开，严格遵守重复规则与区间边界 | 长期重复仍显示，午夜结束不侵占次日；COUNT/UNTIL/EXDATE保留 |
| 来回打开笔记 | 返回主页局部刷新任务、最近笔记、书签等本地数据（日历保持独立订阅刷新） | 搜索、任务筛选与主页DOM保留；不重新启动专注、不触发外部脚本 |
| 壁纸下看标题 | 默认对整页背景启用主题色衬底，可关闭或始终启用 | 深浅色、宽窄屏可读，不改变标题/搜索中轴和两侧工具位置 |
| 每页快捷入口 | 仪表盘设置新增快捷按钮页，支持插件命令、自定义命令/笔记/网址、独立排序与启停 | 缺省沿用全局、空列表只留布局；复制和备份保留，保存失败不丢表单 |
| 主动恢复显示 | 主页更多菜单及命令面板提供“刷新工作台数据” | 只刷新本地数据卡片，避免重载整个插件 |
| 禁用外部请求 | 内置及已保存读书卡在执行脚本前遵守开关 | 不发请求，展示中文状态；不改写用户脚本 |

## 实现边界

- TaskNotes 继续管理任务状态、循环完成与番茄钟，不复制一套计时器或完成逻辑。
- Markdown、data.json、top-area.json 的已有内容和路径保留，不自动移动、批量改名或重置。
- 备份默认不携带凭据；不会把任务笔记、便签原文或 top-area.json 误称为布局备份的一部分。
- 开发与写入验收使用独立笔记库；正式安装只替换 main.js、styles.css、manifest.json，保留本地设置、笔记和既有备份。

## 验证与完成标准

修复当前审计全部13项功能问题及1项条件样式问题，新增对应边界与竞争回归；完成全套自动测试、构建一致性、三件套校验；在独立 Obsidian 中复测导入往返、便签、任务与专注、局部刷新及主题/响应式截图。未实测的真机、外部账户、DST与系统休眠如实列出。

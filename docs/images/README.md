# README 配图说明

三张图片均由 Obsidian 桌面端实际运行界面截图得到，截图时只保留插件内容区域；没有使用生成式模型重绘界面。

- `home-overview.png`：首页、任务看板与六个板块。
- `tasks-agenda.png`：任务日期清单。
- `project-gantt.png`：嵌入首页的项目甘特图。

截图环境：Carrot Home 2.0.1、TaskNotes 4.13.1、Carrot Gantt 1.2.0，Obsidian 默认浅色主题。演示库仅使用公开发行版中的虚构示例，以及“示例主号／示例副号”等演示设置；未使用私人笔记或真实账号配置。

背景由维护者提供，仅用于 README 展示，不随插件安装，也不改变插件默认背景。卡片大小、布局、透明度和窗口缩放均为演示设置，用户可以按自己的需要调整。

项目来自 [ondreu/Hearth](https://github.com/ondreu/Hearth)，来源与许可说明见仓库 [README](../../README.md#hearth-来源与许可)、[LICENSE](../../LICENSE) 和 [NOTICE](../../NOTICE.md)。

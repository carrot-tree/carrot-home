# 顶部便签与专注

顶部工具自 2.1.0 起发布，使用首页既有顶部留白。2.1.1 修正左侧就地折叠，并移除独立“顶部工具”按钮。2.1.2 改为向左收绳，留下固定钉上的单圈绳，点击单圈向右展开。2.1.3 将右侧改为独立圆形计时盘，并加入向右折叠和搜索区可读宽度保护。2.1.4 延后顶部工具的紧凑切换，修正圆盘缩放重心，并按整组图案的可见上沿对齐两侧。

## 主页快捷操作

左侧采用 B“木夹晾晒”：细麻绳、木夹和奶油色便签，深色主题使用暖深色纸张。绳头按钮为向左折叠/向右展开：便签和绳头向左端固定扣收拢，收起后只保留左端固定钉上的一小段单圈绳，点击绳圈即可向右展开。原区域高度与页面布局不随折叠变化。折叠状态单独持久化，不等同于关闭区域。

右侧自2.1.3使用专注主题色的简约箭头，向右收起为真实倒计时胶囊，停在与原收起按钮同高的右上方；点击胶囊或聚焦后按空格／回车展开，计时不会停止，折叠状态在重载后保留。左侧保留木质方框双箭头。主页不新增独立“顶部工具”按钮；显示开关和设置入口位于原视图右上角“更多选项（…）”菜单，原有菜单项目保留。设置页和命令面板仍可使用。

## 设置入口

在 **设置 → Carrot Home → 顶部工具** 管理这两个区域，或在命令面板执行“顶部工具：打开设置”。可以整体隐藏，也可以独立隐藏便签或专注卡；开关重载后保留，不删除便签，不中断 TaskNotes 会话。关闭显示后仍可从设置页打开便签管理、新建便签或计时面板。

便签管理在此直接打开“全部便签”“贴一张”。计时入口打开 TaskNotes 原生面板；默认专注与休息时长通过“TaskNotes 设置”调整，单次时长仍在卡片“更多…”中设置。便签存放目录保留为 `Carrot Home 灵感/`，本轮不提供移动目录，以保护原链接。

## 随手晾晾

用于备忘、临时待办、摘录和随手记录。“贴一张”支持可选标题与正文，至少填写一项；只有正文时用首行作为展示标题。点击便签可“改一改”，也可打开原 Markdown。

编辑器支持保存、取消和 Cmd/Ctrl+Enter。取消或关闭会保留草稿，可明确丢弃；修改显示标题不会重命名文件。外部修改与当前编辑基线冲突时会提示并拒绝覆盖。

双张模式可以拖动木夹排序；“全部便签”提供完整顺序、标题/正文搜索、拖拽、前移/后移和聚焦手柄后的 Alt+方向键替代操作。管理按页容纳全部数据，不截断第 25 张。较窄时顶部一次展示一张，按顺序前后翻页；排序使用便签菜单或全部管理。“收起来”只从顶部撤下，原文保留，可从“收起来的”中“晾回来”。外部改名会跟随索引；文件失效时明确提示，可移除失效引用。

## 专注一刻

使用 TaskNotes 的真实计时服务，当前桌面验证版本为 TaskNotes 4.13.1。缺少依赖时显示提示与设置入口，便签仍有独立入口。

“换任务”搜索真实未完成、未归档任务，优先显示逾期和今天；点击任务标题打开原任务。空闲时默认显示最近选择的任务，主页选择和 TaskNotes 原生面板保持同步；从原任务卡开始专注的任务也会记住，重载后保留。原生面板明确清除选择后，主页不会重新找回旧任务。旧版主页选择会在尚无原生记录时保留，已完成或失效的任务仍提示重新选择。开始、暂停、继续、剩余时间、进度、完成和休息均与同一个服务会话同步；原任务卡和原生番茄面板共享会话与操作保护。

结束需要确认，调用 TaskNotes 自身停止语义，保留未完成的结束记录，不自动完成任务。活动中换任务先确认结束当前轮，再选择新任务。任务文字保持居中，右边的小切换图标随圆盘缩放并保留在圈内，直接打开任务搜索；长标题会省略，悬停可查看全名；结束本轮及其它操作保留在圆盘的“…”菜单。单次时长使用已验证的服务参数，仅影响下一轮，不改全局默认值；默认设置与复杂管理使用 TaskNotes 原生面板。其它 TaskNotes 版本需另行验证。

## 自适应与入口

中间标题与搜索整组保持内容区中轴，可用空间足够时搜索组保持480–640px宽度；不足872px时继续缩小中间区域并将新建笔记改为图标按钮。下方在720px转单列后，顶部仍保留两侧工具，至600px才切为紧凑入口。圆盘围绕可见圆心定位；左侧按晾绳、木夹及绳端按钮的可见最高边缘与圆盘上沿对齐，极窄时略减便签区域高度以保护下方间距。便签架右边界受下方左侧原卡片约束；可用宽度达到220px且高度足够时显示双张，否则单张顺序翻页。专注圆盘独立放在右上方，直径按空间缩放，最大190px；不采用长方形底板。空间进一步不足时使用已有紧凑入口。快捷分类保持38×38px方形，按实际行宽和数量分配8–48px间距，放不下时横向滚动；搜索框及输入区在所有模式均可缩小，避免覆盖新建按钮。原导航和六卡片布局设置保持。双张便签拖动期间不重建其DOM。

## 数据与升级

便签 Markdown 继续使用 `Carrot Home 灵感/`，更新功能显示名称不会批量改名、移动原目录或破坏已有链接。插件目录内独立的 `top-area.json` v2 保存便签索引、收起项、草稿、显示开关和专注选择，不写入原布局设置 `data.json`。

读取旧版 v1 时先备份原 sidecar，再验证和原子替换，保留原顺序与专注选择；未知或损坏格式保留原件并明确报错。桌面写入包含原始字节比较、排他锁和临时文件验证，发生外部索引变更时拒绝覆盖并提示重载。新建同名文件使用不同路径，写入失败时已有原文保留并提供找回入口。

升级前备份插件目录；只替换 `main.js`、`styles.css`、`manifest.json`，保留 `data.json`、`top-area.json`、备份及所有 Markdown。不要把独立测试库中的数据复制到自己的库。

## 验证范围

自动化覆盖便签文本编辑范围、迁移/损坏保护、写入失败与竞争、排序/分页、延迟加载视图、三栏布局分配及原任务专注桥接。独立桌面 Obsidian 中验证了真实鼠标/键盘交互、状态持久化、真实工作与休息流程，此前验证了原计时桥接；本轮101项自动化通过，另对13档图标间距与17档搜索／新建边界做桌面响应式检查，并实测任务快捷切换入口、便签分页和右上方收起／展开。

新增工具尚未完成移动端真机、其它 TaskNotes 版本、长休息完整到时和真实系统休眠验收。原子存储的移动文件适配与异常中断后残留锁的恢复仍需专项验证；没有自动合并跨窗口索引冲突的承诺。

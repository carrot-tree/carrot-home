# 顶部便签与专注

顶部工具为当前开发分支新增功能。仓库中的 manifest 版本沿用 2.0.5；新的 Release 另行发布。

## 随手晾晾

用于备忘、临时待办、摘录和随手记录。“贴一张”支持可选标题与正文，至少填写一项；只有正文时用首行作为展示标题。点击便签可“改一改”，也可打开原 Markdown。

编辑器支持保存、取消和 Cmd/Ctrl+Enter。取消或关闭会保留草稿，可明确丢弃；修改显示标题不会重命名文件。外部修改与当前编辑基线冲突时会提示并拒绝覆盖。

双张模式可以拖动纸夹排序；“全部便签”提供完整顺序、标题/正文搜索、拖拽、前移/后移和聚焦手柄后的 Alt+方向键替代操作。管理按页容纳全部数据，不截断第 25 张。较窄时顶部一次展示一张，按顺序前后翻页；排序使用便签菜单或全部管理。“收起来”只从顶部撤下，原文保留，可从“收起来的”中“晾回来”。外部改名会跟随索引；文件失效时明确提示，可移除失效引用。

## 专注一刻

使用 TaskNotes 的真实计时服务，当前桌面验证版本为 TaskNotes 4.13.1。缺少依赖时显示提示与设置入口，便签仍有独立入口。

“换任务”搜索真实未完成、未归档任务，优先显示逾期和今天；点击任务标题打开原任务。开始、暂停、继续、剩余时间、进度、完成和休息均与同一个服务会话同步；原任务卡和原生番茄面板共享会话与操作保护。

结束需要确认，调用 TaskNotes 自身停止语义，保留未完成的结束记录，不自动完成任务。活动中换任务先确认结束当前轮，再选择新任务。“更多…”中的单次时长使用已验证的服务参数，仅影响下一轮，不改全局默认值；默认设置与复杂管理使用 TaskNotes 原生面板。其它 TaskNotes 版本需另行验证。

## 自适应与入口

三栏基于主页实际可用宽度共同分配空间，尊重原对齐与显示设置。宽松时显示双张便签与完整专注卡；空间收紧后逐步缩小字号、内边距和高度；较窄时切单张便签与精简专注卡；进一步不足时显示两个紧凑入口。标题行高保留，原导航与六卡片不会被新工具推移。双张便签中的拖动期间不重建其 DOM。

也可从 Obsidian 命令面板搜索：

- 随手晾晾：贴一张
- 随手晾晾：全部便签
- 专注一刻：打开
- 顶部工具：显示／隐藏

## 数据与升级

便签 Markdown 继续使用 `Carrot Home 灵感/`，更新功能显示名称不会批量改名、移动原目录或破坏已有链接。插件目录内独立的 `top-area.json` v2 保存便签索引、收起项、草稿、显示开关和专注选择，不写入原布局设置 `data.json`。

读取旧版 v1 时先备份原 sidecar，再验证和原子替换，保留原顺序与专注选择；未知或损坏格式保留原件并明确报错。桌面写入包含原始字节比较、排他锁和临时文件验证，发生外部索引变更时拒绝覆盖并提示重载。新建同名文件使用不同路径，写入失败时已有原文保留并提供找回入口。

升级前备份插件目录；只替换 `main.js`、`styles.css`、`manifest.json`，保留 `data.json`、`top-area.json`、备份及所有 Markdown。不要把独立测试库中的数据复制到自己的库。

## 验证范围

自动化覆盖便签文本编辑范围、迁移/损坏保护、写入失败与竞争、排序/分页、延迟加载视图、三栏布局分配及原任务专注桥接。独立桌面 Obsidian 中验证了真实鼠标/键盘交互、状态持久化、真实工作与休息流程，并检查七档页面宽度下的几何、内容越界、单/双张切换和主要入口。

新增工具尚未完成移动端真机、其它 TaskNotes 版本、长休息完整到时和真实系统休眠验收。原子存储的移动文件适配与异常中断后残留锁的恢复仍需专项验证；没有自动合并跨窗口索引冲突的承诺。
